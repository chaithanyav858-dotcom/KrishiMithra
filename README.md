# KrishiMitra (ಕೃಷಿಮಿತ್ರ) - Pure HTML & CSS Edition
**Smart Agricultural Decision Support System**  
*Department of Computer Science & Engineering, Malnad College of Engineering (MCE), Hassan*

---

## 📌 Overview
This edition of **KrishiMitra** is built **entirely with pure HTML5 and modern CSS3** (zero JavaScript required). It replicates the exact design, layouts, color palettes, responsive cards, bilingual agricultural recommendations (English & Kannada), and farmer workflows of the full system.

It can be opened directly by double-clicking `index.html` in any web browser without running any servers, Node.js, or installing dependencies.

---
